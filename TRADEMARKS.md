# Marks

G12 legal is **open**. This page is usage hygiene, not a registration filing.

## AINav marks (ours)

Use **AINav**, **AINav Control Plane**, and **AINAV.Institute** only to name this company and Job C product. Do not use them for a second control plane, a Copilot wrapper, or a soft HITL vote.

## Microsoft marks (theirs)

Use Microsoft marks only as integration names: Entra (seats), Teams (notify), Business Central / Sales (SoR twins), Azure (host), Microsoft 365 E7 / Purview / Sentinel (audit sink).

Do not:

- say AINav is a Microsoft product, Copilot feature, or Power Automate approval
- sell `COPILOT_*`, `PURVIEW_PLANE`, or `SENTINEL_GOV` as SKUs
- treat a Teams chat as `seat_a` or `seat_b`

## Competitor marks

Do not provision competitor names (ServiceNow, SailPoint, Okta, Palantir, UiPath, Agentforce, Joule, and the catalog alias list) as AINav packs. The admit plane is the product; those systems are not.
